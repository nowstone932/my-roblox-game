# 흑송 벌목장 공략

게임 코드를 그대로 읽고 정리한 공략입니다. 숫자(초, 개수, 피해량)는 전부 `src/shared/Config.luau`에 있는 지금 값이에요. Config를 바꾸면 이 문서 숫자도 달라집니다.

## 한눈에 보기

- 제한 시간은 **15분**. 시작 지점은 맵 남쪽 끝의 고장난 수색대 차.
- 탈출 방법은 4가지이고, 한 라운드에 여러 개를 동시에 노려도 됩니다.
- 탈출 부품 위치는 **매 라운드 무작위**로 바뀝니다. 대신 "놓일 수 있는 장소"는 정해져 있어요 (아래 표).
- 탈출 부품(퓨즈, 배터리, 룬 등)은 은은하게 빛나고 **반짝이 입자**가 나와서 어두워도 찾기 쉽습니다.
- 부품을 설치할 때마다 괴물이 조금씩 빨라집니다 (설치 1번당 추격 속도 +1.5).

## 지도

```
                 [정문]  [발전기 오두막]
                    |
   [헬기장]          |              [제단 + 돌무덤]  ← 괴물 둥지
      |             |
   [감시탑] ---- [벌목 캠프 / 제재소 / 트럭] ---- [폐주유소 + 고물장]
                    |
               [고장난 차 = 시작]
```

- 북쪽: 전기 정문, 정문 오른쪽에 발전기 오두막
- 중앙: 벌목 캠프(오두막 3채), 제재소, 벌목 트럭
- 서쪽: 레인저 감시탑(꼭대기에 무전기), 북서쪽에 헬기장
- 동쪽: 폐주유소(창고, 주유기), 그 북쪽에 고물장(폐차 6대)
- 북동쪽: 옛 제단과 돌무덤. 가는 길이 없어서 숲을 헤치고 가야 함

## 조작

| 키 | 동작 |
|---|---|
| WASD / 마우스 | 이동 / 시점 (1인칭) |
| Shift | 달리기. 약 5초 달리면 기력이 바닥나고, 다 차는 데 약 8초 |
| E (꾹 누르기) | 줍기, 쪽지 읽기, 숨기/나오기, 부품 설치, 시동, 구조 요청, 쓰러진 동료 살리기 |
| C | 제작 창 열기/닫기 |
| 1 ~ 9 | 핫바의 도구 들기 |
| 왼쪽 클릭 | 들고 있는 도구 사용 |
| F | 손전등 켜기/끄기 |
| Q / E | (죽었거나 탈출한 뒤) 관전할 동료 바꾸기 |

## 제작법 (C키)

| 만들 것 | 재료 | 효과 |
|---|---|---|
| 손도끼 | 나무 2 + 고철 1 | 근접 공격 18 피해, 조용함. 1개만 가질 수 있음 |
| 조명탄 총 | 고철 3 + 나무 1 + 화약 1 | 원거리 30 피해. **총소리가 괴물을 부름**. 1개만 |
| 조명탄 x3 | 고철 1 + 화약 1 | 조명탄 총 탄약 3발 |
| 섬광탄 | 고철 1 + 화약 2 | 던지면 1.2초 뒤 폭발, 반경 30 안의 괴물 5초 기절 |
| 곰덫 | 고철 3 | 앞쪽 바닥에 설치. 괴물이 밟으면 6초 묶임 |
| 붕대 | 약초 1 + 천 1 | 체력 50 회복 |
| 봉인 말뚝 | 룬 조각 3 + 나무 2 | 쓰러진 괴물에게 박으면 봉인. 1개만 |

### 재료 찾는 곳

재료는 주우면 45~60초 뒤 다른 곳에 다시 생깁니다.

| 재료 | 주로 있는 곳 |
|---|---|
| 고철 | 고물장 폐차 옆, 주유소 창고 선반, 제재소 바닥, 작업대 |
| 나무 | 통나무 더미, 제재소 바닥, 모닥불 옆, 숲 바닥 |
| 약초 | 숲속 약초 군락, 숲 바닥 |
| 화약 | 화약 상자 (캠프 1곳, 감시탑 1곳, 주유소 근처 2곳), 주유소 창고 선반 |
| 천 | 빨랫줄, 오두막 침대, 오두막 바닥 |

**화약은 맵 전체에 8개뿐**이라 가장 귀합니다. 섬광탄 하나에 2개가 들어가니, 조명탄 총과 섬광탄 중 뭘 만들지 미리 정하세요.

## 탈출 루트 1: 정문 (퓨즈)

**필요한 것:** 퓨즈 3개 (맵에 4개 있음)

**퓨즈가 있을 수 있는 곳 (벽에 붙은 전기함):**
- 벌목 캠프 오두막 3채 안
- 제재소 기둥
- 감시탑 다리
- 주유소 창고 안, 주유소 바깥 벽

(발전기 오두막 전기함에는 퓨즈가 절대 안 나옵니다.)

**순서:**
1. 전기함을 돌면서 퓨즈를 모은다.
2. 북쪽 정문 옆 **발전기 오두막**으로 가서 발전기에 E. 가진 퓨즈가 한 번에 다 들어갑니다.
3. 여러 명이 나눠서 넣어도 됩니다 (발전기 칸이 노랗게 켜짐 1/3, 2/3…).
4. 3개가 다 들어가면 발전기가 돌고 정문이 올라갑니다. **이때 큰 소리가 나서 근처 괴물이 조사하러 옵니다.**
5. 정문을 지나 바깥 초록 구역에 닿으면 탈출.

**팁:** 정문은 한 번 열리면 계속 열려 있어서 다른 동료도 나중에 걸어 나갈 수 있어요. 가장 안전한 루트입니다.

## 탈출 루트 2: 트럭

**필요한 것:** 자동차 배터리 1 + 연료통 1 + 트럭 열쇠 1 (각각 맵에 1개씩만 있음)

| 부품 | 있을 수 있는 곳 |
|---|---|
| 자동차 배터리 | 고물장 폐차 보닛 위, 주유소 창고 선반 |
| 연료통 | 주유소 주유기 옆, 제재소 바닥 |
| 트럭 열쇠 | 오두막 벽의 열쇠걸이 (캠프 오두막 3채, 주유소 창고, 발전기 오두막 중 하나) |

**순서:**
1. 세 부품을 모아 캠프의 **벌목 트럭**에 E ("부품 설치"). 들고 있는 것만 설치되고, 여러 명이 나눠서 설치해도 됩니다.
2. 셋 다 설치되면 "시동 걸기"로 바뀝니다. E를 3초 꾹 눌러 시동.
3. **엔진 소리가 맵 대부분에 들려서 괴물이 바로 옵니다.**
4. 20초 동안 버틴다. 출발하는 순간 **트럭에서 18스터드 안에 있는 사람만** 탈출합니다. 그 순간 쓰러져 있는 사람은 제외돼요.

**팁:** 시동 걸기 전에 트럭 주변에 곰덫을 깔고, 섬광탄을 준비하세요. 트럭 밑에 숨을 수도 있지만, 숨어 있으면 출발할 때 탈출로 안 칠 수도 있어요 (아래 "확인 필요" 참고).

## 탈출 루트 3: 무전기 + 헬기

**필요한 것:** 안테나 부품 2개 (맵에 3개 있음)

**안테나가 있을 수 있는 곳:**
- 감시탑 주변 나무 상자 위
- 헬기장 가장자리 보급 상자 위
- **고물장 폐차 옆** (반대편 동쪽이라 멀어요)

**순서:**
1. 안테나 2개를 들고 서쪽 **감시탑 꼭대기**로 사다리를 타고 올라간다 (사다리는 남쪽 면).
2. 무전기에 E ("안테나 설치"). 나눠서 설치해도 됩니다.
3. 2개가 들어가면 "구조 요청"으로 바뀜. E를 2초 꾹. **큰 소리가 나서 괴물이 옵니다.**
4. **90초 기다리면** 북서쪽 헬기장에 헬기가 옵니다.
5. 헬기는 **40초만 기다립니다.** 그동안 헬기장 가운데(반경 17스터드)에 서 있으면 탈출. 쓰러진 상태로는 탈출이 안 되니 먼저 살려야 해요.

**팁:** 90초 동안 감시탑 위에 있으면 괴물이 아래로 몰려올 수 있어요. 일찍 헬기장 근처로 이동해서 숨을 곳을 확인해 두세요. 헬기가 도착할 때도 큰 소리가 납니다. 40초가 지나면 헬기는 떠나고 다시 부를 수 없어요.

## 탈출 루트 4: 괴물 봉인 (가장 어려움, 가장 보상이 큼)

**필요한 것:** 룬 조각 3개(맵에 4개) + 나무 2 → 봉인 말뚝, 그리고 괴물을 쓰러뜨릴 무기

**룬 조각이 있을 수 있는 곳:** 북동쪽 **제단** 위와 주변, 제단 근처 **돌무덤**(돌 4개가 쌓인 탑) 7곳

**순서:**
1. 룬 3개를 모은다. **한 사람이 3개를 다 가져야 합니다.** 아이템을 건네주는 기능이 없어요.
2. 나무 2개를 더해 C키로 봉인 말뚝 제작.
3. 괴물 체력은 **300**. 손도끼(18)나 조명탄 총(30)으로 0까지 깎는다. 손도끼만으로는 17번, 조명탄만으로는 10발.
4. 괴물이 쓰러지면 **40초 안에** 말뚝을 들고(핫바) 괴물 가까이(14스터드 안) 가서 왼쪽 클릭.
5. 성공하면 **살아 있는 전원이 탈출**합니다 (쓰러져 있는 동료도 포함).

**놓치면:** 40초 뒤 괴물이 체력 300으로 다시 일어납니다. 말뚝은 쓰지 않았다면 그대로 남아요.

**팁:**
- 괴물은 처음 **90초 동안 제단 근처에만** 있습니다. 시작하자마자 룬을 주우러 가면 괴물 바로 옆이에요. 다른 탈출 소리(발전기, 시동, 무전)로 괴물을 다른 곳으로 끌어낸 뒤 가는 게 안전합니다.
- **기절한 괴물도 맞으면 피해를 입습니다.** 섬광탄(5초)이나 곰덫(6초)으로 묶고 그동안 때리세요. 기절 중에는 맞아도 반격하러 오지 않아요.
- 조명탄 총은 쏠 때마다 큰 소리가 나지만, 어차피 싸우는 중이라면 상관없습니다.
- 여러 명이 동시에 때리면 훨씬 빨리 쓰러집니다.

## 괴물(숲지기)에게서 살아남기

### 괴물이 나를 알아채는 방법
- **눈:** 90스터드 안에서 나무나 벽에 가려지지 않으면 봅니다.
- **귀:** 16스터드 안이면 무조건 알아챔. **달리면 45스터드**, 걸으면 20스터드 안에서 발소리를 들어요.
- **큰 소리:** 조명탄 총(160), 발전기(120), 트럭 시동(400), 무전/헬기(400), 손도끼 휘두르기(40) 범위 안이면 조사하러 옵니다.
- 놓치면 마지막으로 본 곳 주변을 18초 동안 뒤지고, 근처 오두막 안까지 들어옵니다.

### 속도
- 내 걷기 15, 달리기 23 (약 5초만).
- 괴물 배회 11, **추격 19**, 부품을 설치할 때마다 +1.5. 부품 3개를 넣으면 추격 23.5로 **달리기보다 빨라집니다.**
- 돌진할 때는 순간적으로 1.7배.

그래서 진행이 많이 될수록 "도망"보다 "숨기, 기절시키기"가 중요해집니다.

### 숨기 (옷장 / 차 밑)
**숨을 수 있는 곳:**
- 옷장: 캠프 오두막 3채, 주유소 창고, 발전기 오두막
- 차 밑: 시작 지점 수색대 차, 고물장 폐차 6대, 벌목 트럭

**규칙:**
- 숨어 있으면 괴물이 나를 보지도 듣지도 못합니다.
- 괴물이 **12스터드 안에 있으면 숨을 수 없어요.** 미리 거리를 벌려야 합니다.
- **25초**가 지나면 숨이 차서 저절로 나옵니다. 나오기 전에 E로 직접 나와도 돼요.
- **쫓기던 중에 숨는 걸 들키면**(괴물이 45스터드 안에서 쫓고 있었으면) 괴물이 와서 문 앞을 3.5초 뒤집니다. 이때 **35% 확률로 끌려나오고 40 피해**를 입어요. 쫓기지 않을 때 숨으면 들킬 일이 없습니다.

### 손전등 (F)
- 괴물이 45스터드 안에 오면 **손전등이 깜빡입니다.** 이게 괴물이 근처에 있다는 신호예요.
- 가끔 일어나는 "정전" 이벤트 때도 깜빡입니다.
- 손전등을 켜도 괴물에게 더 잘 보이게 되지는 않습니다 (괴물 시야는 손전등과 상관없음). 그러니 그냥 켜고 다녀도 돼요.

### 섬광탄 / 곰덫
- **섬광탄:** 1.2초 뒤 터지니까 괴물이 오는 방향으로 조금 앞에 던지세요. 반경 30 안이면 5초 기절.
- **곰덫:** 내 앞 5스터드 바닥에 깔립니다. 괴물이 지나갈 길(문 앞, 트럭 옆, 좁은 길)에 미리 깔아두세요. 밟으면 6초 묶임. 한 번 쓰면 사라집니다.

### 맞았을 때 / 쓰러졌을 때
- 괴물 한 대에 35 피해. 체력 100이면 세 번째 맞을 때 **쓰러짐**(바로 죽지 않음).
- 쓰러지면 기어다니기만 할 수 있고, 괴물은 쓰러진 사람은 무시하고 떠납니다.
- **35초 안에 동료가 와서 E를 4초 꾹** 누르면 체력 40으로 일어납니다. 못 살리면 사망.
- 죽으면 들고 있던 탈출 부품이 그 자리에 떨어집니다. 동료가 주워 갈 수 있어요.
- 붕대(약초 + 천)로 미리 체력을 채워두세요.

### 괴물의 무서운 행동 (알고 있으면 덜 놀라요)
- 멀리서 발견하면 바로 오지 않고 **3~6초 가만히 지켜보다가** 갑자기 돌진하기도 합니다.
- 45초 동안 아무도 못 찾으면 **내 뒤쪽 45~65스터드 어딘가로 순간이동**해서 다가옵니다.
- 오두막 문 앞에서는 몸을 숙이고 기어 들어옵니다. 집 안도 안전하지 않아요.

## 추천 공략 순서 (2~5명)

1. **처음 90초 (괴물이 둥지에 있는 시간):** 흩어져서 재료와 부품을 최대한 줍습니다. 캠프 오두막 3채(퓨즈, 열쇠, 천, 옷장)와 제재소(퓨즈, 연료통, 나무, 고철)가 시작 지점에서 가깝고 알찹니다.
2. 손도끼(나무 2 + 고철 1)는 싸서 한 명당 하나씩 만들어 두면 좋아요. 붕대도 1~2개.
3. **정문 루트를 1순위로.** 퓨즈만 모으면 되고, 열린 뒤로 계속 열려 있습니다.
4. 퓨즈가 잘 안 보이면 트럭이나 무전으로 바꾸세요. 주유소 쪽(배터리, 연료통, 퓨즈 2곳)을 한 번에 훑으면 효율적입니다.
5. 실력이 붙으면 봉인 도전. 화약을 모아 섬광탄 2개와 곰덫을 준비하고, 다른 동료가 소리로 괴물을 끌어올 때 다같이 공격.
