# 로벅스 상점 설정하기

대기실 화면 왼쪽에 "상점 [B]" 꼬리표가 있어요. `B` 키를 누르면 상점 창이 열리고 마우스 커서가 나타나서 구매 버튼을 누를 수 있습니다. 다시 `B` 를 누르면 닫혀요.
(설정 창도 같은 방식으로 `P` 키로 열고 닫습니다.)

코드는 이미 다 들어 있고, **Creator Hub에서 물건을 만들고 숫자 ID만 넣으면** 판매가 시작됩니다.
ID를 넣기 전에는 상점에 "준비 중"이라고 보여요.

## 파는 물건

### 게임패스 (한 번 사면 계속)

| 이름 | 추천 가격 | 내용 | Config 이름 |
|---|---|---|---|
| 스타터 키트 | 149 | 매 판 조명탄 총 + 조명탄 6발 + 손도끼 | `StarterKitPassId` |
| 숲지기 추적기 | 199 | `T` 키: 10초 동안 괴물 위치 표시, 60초 뒤 다시 사용 | `TrackerPassId` |
| 숲지기 변신 | 249 | `G` 키: 한 판에 한 번, 20초 동안 진짜 숲지기 모델로 변신 (3인칭 시점). 괴물이 공격하지 않음 | `DisguisePassId` |
| 손전등 불빛 색 | 49 | 상점에서 누를 때마다 색이 바뀜 | `LightColorPassId` |

### 개발자 상품 (살 때마다 1개)

| 이름 | 추천 가격 | 내용 | Config 이름 |
|---|---|---|---|
| 부활 | 25 | 죽거나 쓰러진 자리에서 일어남 (한 판에 한 번) | `ReviveProductId` |
| 섬광탄 3개 | 39 | 다음 판에 들고 시작 (한 판에 한 묶음) | `FlashbangPackProductId` |
| 건전지 3개 | 19 | 다음 판에 들고 시작 (한 판에 한 묶음) | `CellPackProductId` |
| 팀 보급 상자 | 79 | 같이 간 팀원 모두에게 붕대 1개 + 건전지 2개 | `SupplyCrateProductId` |

대기실에서 산 소모품은 "보관함"에 들어가고, 숲에 들어갈 때 종류마다 1개씩 자동으로 꺼내 줍니다.
여러 개 사 두면 다음 판, 그다음 판에 차례로 쓰여요.

## 만드는 순서

1. Studio에서 `파일` → `Roblox에 게시` 로 게임을 올립니다. (이미 올렸으면 건너뛰기)
2. https://create.roblox.com 에 들어가서 **작품(Creations)** → 내 게임을 누릅니다.
3. 왼쪽 메뉴 **수익 창출(Monetization)** → **패스(Passes)** → **패스 만들기**
   - 이름, 설명, 그림(아무 그림이나 가능)을 넣고 만들기
   - 만든 패스를 눌러 **판매(Sales)** 에서 "판매 중"을 켜고 가격을 넣기
   - 위 표의 게임패스 4개를 이렇게 만듭니다.
4. 같은 메뉴의 **개발자 상품(Developer Products)** → **개발자 상품 만들기**
   - 이름과 가격을 넣고 만들기. 위 표의 상품 4개를 만듭니다.
5. 각 물건의 **ID 숫자**를 복사합니다. (목록에서 물건 옆 `⋯` → "ID 복사", 또는 주소창의 숫자)
6. ID 8개를 Claude에게 보내 주세요. 대신 넣어 드려요.
   직접 넣으려면 `src/shared/Config.luau` 의 `Config.Monetization` 에서 `0` 을 ID로 바꾸면 됩니다.
   ```lua
   StarterKitPassId = 123456789,
   ```

전부 다 만들 필요는 없어요. ID가 0인 물건은 "준비 중"으로만 보이고 나머지는 정상으로 팔립니다.

## Studio에서 미리 써 보기

- Studio 테스트에서는 **게임패스를 전부 가진 것으로** 쳐요. 그래서 패스를 만들기 전에도 `T`(추적기), `G`(변신)를 써 볼 수 있습니다.
  끄려면 `Config.Monetization.StudioOwnsAllPasses = false`.
- Studio에서 구매 버튼을 누르면 로벅스가 빠지지 않는 **테스트 구매**가 됩니다.
- 보관함 저장은 `게임 설정` → `보안` → **Studio의 API 서비스 접근 허용**을 켜야 됩니다. 안 켜면 그 테스트 동안만 유지돼요.

## 숫자 바꾸기

`src/shared/Config.luau` 의 `Config.Shop` 에서 바꿀 수 있어요.

- `TrackerTime`, `TrackerCooldown`: 추적기가 켜져 있는 시간, 다시 쓸 때까지 시간
- `DisguiseTime`, `DisguisePerRound`: 변신 시간, 한 판에 쓸 수 있는 횟수
- `DisguiseHeight`, `DisguiseCamera`: 변신했을 때 키, 3인칭 카메라 거리
- `Items` 의 `icon`, `tint`, `tag`: 상점 카드의 그림 글자, 바탕색, 딱지
- `FlashbangPack`, `CellPack`, `CrateMedkit`, `CrateCell`: 묶음에 든 개수
- `LightColors`: 손전등 색 목록

가격은 코드가 아니라 Creator Hub에서 정합니다. (상점 화면은 그 가격을 자동으로 불러와요)

## 지킨 원칙

- 돈으로 사는 물건은 전부 게임 안에서도 공짜로 구할 수 있거나(섬광탄, 건전지, 총), 짧게만 쓸 수 있어요(추적기, 변신).
- 괴물을 죽이거나 탈출을 건너뛰는 물건은 없습니다.
- 뽑기(랜덤 상자)는 없습니다. Roblox 규정상 확률 표시가 필요하고 일부 나라에서는 금지예요.
