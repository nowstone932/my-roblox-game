# 소리 · 배경음악(BGM) 넣기

소리를 트는 코드는 이미 다 들어 있어요. **소리 번호(ID)만 넣으면** 바로 켜집니다.
번호를 넣는 곳은 딱 한 파일: **`src/shared/SoundList.luau`**

> **이미 거의 다 채워져 있어요.** Creator Store(로블록스 공식 무료 음원 위주)에서 이름이 맞는 소리를 골라 번호를 넣어뒀어요.
> 다만 클라우드에서는 직접 들어볼 수 없어서, Studio에서 플레이해보고 **안 나오거나 어울리지 않는 소리만** 아래 방법으로 바꾸면 돼요.
> (줍기 '딩', 도끼, 제작 소리는 로블록스 기본 내장 소리라 항상 나와요.)

---

## 1. 소리 찾기 (5분)

1. Roblox Studio 위쪽 **보기(View)** → **도구 상자(Toolbox)**
2. 도구 상자 위쪽 카테고리에서 **오디오(Audio)** 선택
3. 검색창에 아래 표의 영어 검색어를 입력 → ▶ 눌러서 들어보기
4. 마음에 들면 그 소리 **우클릭 → "에셋 ID 복사(Copy Asset ID)"**
5. VS Code에서 `src/shared/SoundList.luau` 를 열고, 해당 줄의 `id = 0` 의 `0` 을 지우고 붙여넣기 → 저장

```lua
ForestAmbience = { id = 0, volume = 0.5, looped = true, music = true },
-- ↓ 이렇게
ForestAmbience = { id = 1234567890, volume = 0.5, looped = true, music = true },
```

💡 **팁:** 만든 사람이 **Roblox** 로 되어 있는 소리(로블록스 공식 무료 음원)를 고르면 거의 확실하게 재생돼요.
웹 브라우저로 찾고 싶으면 Creator Hub → **Creator Store → Audio** 에서도 똑같이 찾을 수 있어요 (주소창의 숫자가 ID).

## 2. 어떤 소리가 필요한가요?

**⭐ = 먼저 넣으면 분위기가 확 사는 것** (이 6개만 넣어도 충분히 무서워져요)

### 배경음악 / 배경음
| 이름 | 언제 나오나 | 검색어 |
|---|---|---|
| ⭐ `ForestAmbience` | 라운드 내내 (반복) | `night forest ambience`, `wind forest` |
| ⭐ `TensionMusic` | 괴물이 가까울수록 점점 커짐 (반복) | `horror drone`, `dark ambient tension` |
| ⭐ `ChaseMusic` | 괴물이 쫓아올 때 (반복) | `horror chase`, `intense chase music` |
| ⭐ `Heartbeat` | 괴물이 가깝거나 체력이 45% 아래일 때 (반복) | `heartbeat` |
| `LobbyMusic` | 라운드 시작 전 대기 시간 (반복) | `creepy music box`, `sad piano horror` |
| `RoundStart` | 라운드 시작 순간 | `horror bell`, `deep impact` |
| `Victory` | 탈출 성공 | `victory short`, `relief` |
| `Defeat` | 사망 / 시간 초과 | `horror sting`, `game over horror` |

### 괴물 (괴물 위치에서 들려서 방향을 알 수 있어요)
| 이름 | 언제 | 검색어 |
|---|---|---|
| ⭐ `MonsterScream` | 플레이어를 발견했을 때 | `monster roar`, `creature scream` |
| ⭐ `MonsterGrowl` | 돌아다니며 가끔 | `monster growl`, `creature growl` |
| `MonsterBreath` | 늘 몸에 붙어서 (반복) | `monster breathing`, `heavy breathing` |
| `MonsterFootstep` | 걸을 때 (지금은 임시 소리) | `heavy footstep`, `giant footstep` |
| `MonsterHurt` | 맞았을 때 | `monster hurt`, `creature pain` |
| `MonsterVanish` | 연기 속으로 사라질 때 | `whoosh dark`, `ghost whoosh` |
| `MonsterSealed` | 봉인 성공 | `magic explosion`, `spell impact` |

| 이름 | 언제 | 검색어 |
|---|---|---|

## 3. 크기 · 높낮이 조절

같은 줄의 숫자를 바꾸면 돼요.
- `volume = 0.5` → 크기. 너무 크면 0.3, 작으면 1.2 처럼
- `pitch = 0.8` → 1보다 작으면 낮고 느리게 (괴물 소리에 좋음), 크면 높고 빠르게
- 파일 맨 위 `MasterVolume` → 음악 전체 / 효과음 전체 크기

## 4. 소리가 안 나요!

1. Studio에서 ▶ Play 한 뒤 **출력(Output)** 창을 보세요.
   `[소리] 불러오지 못한 소리가 있어요 …` 라고 나오면 거기 적힌 이름의 ID가 막힌 소리예요 → 다른 소리로 바꿔주세요.
2. 내 컴퓨터의 소리 파일(mp3/ogg)을 쓰고 싶으면: Creator Hub → **Creations → Development Items → Audio → 업로드**
   (무료로 매달 일정 개수까지 올릴 수 있어요). 올리고 나서 나온 번호를 넣으면 됩니다.
3. 게임을 공개(Public)로 올렸는데 소리가 안 나면: 그 소리가 "다른 게임에서 사용 허용"이 꺼져 있는 거예요. 내가 올린 소리거나 Roblox 공식 소리를 쓰면 문제 없어요.
