# 시작하기 (Rojo 설치부터 플레이까지)

이 게임의 코드는 Roblox Studio 안이 아니라 이 저장소의 `src/` 폴더에 들어 있어요.
**Rojo**라는 도구가 컴퓨터의 코드 파일을 Studio로 실시간 복사해 줍니다.
그래서 코드는 VS Code에서 고치고, 테스트는 Studio에서 하는 방식이에요.

순서대로 한 번만 해두면 다음부터는 "4. 매일 작업하는 방법"만 하면 됩니다.

---

## 1. 필요한 프로그램 설치

1. **Roblox Studio** – 이미 설치되어 있으면 넘어가세요.
2. **VS Code** – https://code.visualstudio.com 에서 받아 설치합니다.
3. **Git** (코드 내려받기용) – 둘 중 편한 걸로
   - 쉬운 방법: **GitHub Desktop** (https://desktop.github.com) 설치 후 GitHub 계정으로 로그인
   - 또는 Git 명령어: https://git-scm.com

## 2. 이 저장소를 내 컴퓨터로 받기

**GitHub Desktop을 쓰는 경우**
1. `File` → `Clone repository...`
2. `nowstone932/my-roblox-game` 선택 → 저장할 폴더 고르고 `Clone`
3. 아직 PR이 합쳐지기(merge) 전이라면, 위쪽 `Current branch`에서 `claude/project-thread-rgu8fr` 브랜치를 선택하세요.

**명령어를 쓰는 경우**
```bash
git clone https://github.com/nowstone932/my-roblox-game.git
cd my-roblox-game
```

## 3. Rojo 설치 (VS Code 확장 + Studio 플러그인)

1. VS Code를 열고 `File` → `Open Folder...` 로 방금 받은 `my-roblox-game` 폴더를 엽니다.
2. 왼쪽 막대의 **확장(Extensions)** 아이콘(네모 4개 모양)을 누르거나 `Ctrl+Shift+X`.
3. 검색창에 **`Rojo`** 입력 → **"Rojo - Roblox Studio Sync"** (만든 사람: evaera) 를 `Install`.
   - 같이 깔면 좋은 것: **"Luau Language Server"** (JohnnyMorganz) – 코드 자동완성/오류 표시
4. 설치가 끝나면 VS Code 아래쪽 상태줄에 **Rojo** 버튼이 생깁니다. 눌러서 메뉴를 엽니다.
   (안 보이면 `Ctrl+Shift+P` → `Rojo: Open menu` 입력)
5. 메뉴에서 **"Install Roblox Studio plugin"** 을 누릅니다. → Studio에 Rojo 플러그인이 설치돼요.
   - Rojo 프로그램 자체가 없다고 나오면, 메뉴가 알려주는 대로 설치 버튼을 누르면 자동으로 깔립니다.
6. Studio가 켜져 있었다면 한 번 껐다가 다시 켜세요.

## 4. 매일 작업하는 방법 (동기화)

1. **VS Code**에서 Rojo 메뉴 → `default.project.json` 옆의 **Start (▶)** 를 누릅니다.
   - 아래쪽에 `Rojo server listening on port 34872` 비슷한 메시지가 나오면 성공.
2. **Roblox Studio**에서 `New` → **Baseplate** 템플릿으로 새 장소를 엽니다.
   (처음 한 번만. 다음부터는 저장해둔 장소를 열면 돼요)
3. Studio 위쪽 **Plugins** 탭 → **Rojo** 버튼 → 뜨는 창에서 **Connect**.
   - 연결되면 `ServerScriptService > Server`, `ReplicatedStorage > Shared`,
     `StarterPlayer > StarterPlayerScripts > Client` 에 스크립트들이 생깁니다.
4. Studio에서 **▶ Play** (F5) 를 누르면 게임이 시작됩니다.
5. 이제 VS Code에서 파일을 고치고 저장하면 Studio에 **자동으로 반영**돼요.
   (Play 중에는 반영이 안 되니, 멈추고 다시 Play 하세요)

> ⚠️ Studio의 Explorer에서 `Server`, `Shared`, `Client` 안의 스크립트를 **직접 고치지 마세요.**
> 다음 동기화 때 VS Code 쪽 파일로 덮어써집니다. 코드는 항상 VS Code에서 고칩니다.
> 맵 꾸미기(나무, 건물 배치 등)는 Studio에서 직접 해도 괜찮아요.

## 5. 게임 방법

### 대기실 (게임 시작 전)
- 접속하면 **대기실**에서 시작해요. 앞쪽 벽에 색깔 방이 4개 있습니다.
- 방 **색깔 바닥에 올라서면** 그 방에 들어간 거예요. 방 하나에 **최대 5명**, 꽉 찬 방에 들어가면 방 앞으로 밀려나요.
- 첫 사람이 들어가면 **30초 카운트다운**이 시작되고, 0초가 되면 **그 방 사람들만** 숲으로 출발합니다.
- 카운트다운 중에 방 밖으로 나가면 빠지고, 방이 비면 카운트다운이 취소돼요.
- 방 입구 위 전광판과 화면 위쪽에 인원(예: 3/5명)과 남은 시간이 보여요.
- 판이 끝나면 10초 뒤 모두 대기실로 돌아옵니다.
- 숫자(방 개수, 최대 인원, 카운트다운 초)는 `src/shared/Config.luau` 의 `Config.Lobby` 에서 바꿔요.

**출발 방식 두 가지**
- 게임을 **게시(Publish)한 뒤 실제 서버**에서는: 방마다 **새 전용 서버**가 만들어지고 그 방 사람들만 순간이동해요. 그래서 4개 방이 동시에 각자 다른 숲에서 플레이할 수 있어요.
- **Studio 테스트**에서는 순간이동이 안 되기 때문에, 같은 서버 안의 숲으로 출발해요. 이때 숲은 한 번에 한 팀만 쓸 수 있어서, 다른 방은 "다른 팀이 숲에 있어요"라고 기다렸다가 앞 팀이 끝나면 출발해요.
- 실제 서버에서도 같은 서버 방식을 쓰고 싶으면 `Config.Lobby.UseTeleport = false` 로 바꾸세요.

**여러 명으로 테스트하는 법 (Studio)**
1. 위쪽 **테스트(Test)** 탭 → **클라이언트 및 서버(Clients and Servers)** 칸에서 플레이어 수를 **2~3명**으로 고르고 **시작(Start)**.
2. 창이 여러 개 뜹니다 (서버 창 1개 + 플레이어 창 여러 개). 플레이어 창마다 같은 방 / 다른 방에 들어가 보세요.
3. 다 보면 서버 창에서 **정리(Cleanup)** 를 눌러 모두 닫아요.

### 스토리
1998년 가을, 강원도 산속 "흑송 벌목장". 벌목꾼 일곱 명이 사라졌고, 플레이어들은 그들을 찾으러 온 수색대입니다.
숲 입구에서 차가 멈췄고, 숲에는 사슴 두개골 얼굴의 "숲지기"가 돌아다닙니다.
곳곳에 떨어진 **쪽지(E로 읽기)** 가 탈출 방법의 단서예요.

### 탈출 방법 4가지 (왼쪽 위 목표 패널에 진행 상황 표시)
| 루트 | 필요한 것 | 위험 요소 |
|---|---|---|
| 정문 | 퓨즈 3개 → 정문 옆 발전기 오두막 | 발전기 소리 |
| 트럭 | 배터리 + 연료통 + 트럭 열쇠 → 캠프의 벌목 트럭 | 시동 후 20초 동안 트럭 옆에서 버텨야 함 (아주 시끄러움) |
| 무전 | 안테나 부품 2개 → 서쪽 감시탑 꼭대기 무전기 | 구조 요청 후 90초 기다렸다가 헬기장으로 |
| 봉인 | 룬 조각 3개로 봉인 말뚝 제작 → 괴물을 쓰러뜨린 뒤 40초 안에 박기 | 괴물과 정면 승부. 성공하면 살아있는 전원 탈출 |

탈출 부품 위치는 **매 라운드 바뀝니다.** 죽으면 들고 있던 부품은 그 자리에 떨어져요.

### 조작
| 키 | 동작 |
|---|---|
| WASD / 마우스 | 이동 / 시점 (1인칭) |
| Shift | 달리기 (기력 소모) |
| E (꾹) | 줍기, 쪽지 읽기, 옷장/차 밑에 숨기, 부품 설치 |
| Q / E | (죽었거나 탈출했을 때) 관전할 동료 바꾸기 |
| C | 제작대 열기/닫기 |
| 1 ~ 9 | 핫바의 도구 들기 (제작한 도구는 화면 아래 핫바에 들어가요) |
| 왼쪽 클릭 | 들고 있는 도구 사용 |
| F | 손전등 |

### 도구
| 도구 | 효과 |
|---|---|
| 손도끼 | 근접 공격, 조용함 |
| 조명탄 총 | 원거리 공격 + 맞은 곳을 잠깐 밝힘. **총소리가 괴물을 부름** |
| 섬광탄 | 던지면 1.2초 뒤 폭발, 괴물 5초 기절 |
| 곰덫 | 바닥에 설치, 괴물이 밟으면 6초 묶임 |
| 붕대 | 체력 50 회복 |
| 봉인 말뚝 | 쓰러진 괴물에게 사용 → 영구 봉인 |

### 괴물(숲지기) 특징
- 보이면 쫓아오고, 아주 가까우면 소리로도 알아챔. **나무 뒤로 숨으면 시야가 가려짐**
- **달리면 발소리가 멀리(45스터드) 들림**, 걸으면 가까이(20스터드)서만 들림
- 벽이나 집 뒤에 숨어도 **길찾기로 돌아서 옴**. 놓치면 마지막으로 본 곳과 도망간 방향, 근처 오두막 안까지 뒤짐
- 라운드 시작 후 90초 동안은 북동쪽 둥지(제단) 근처에만 있음
- 총소리, 트럭 시동, 무전, 발전기 소리를 듣고 조사하러 옴
- **옷장이나 차 밑(시작 지점 차, 고물장 차, 벌목 트럭)에 숨으면 못 찾음** (괴물이 바로 옆이면 숨을 수 없고, 25초 지나면 숨이 차서 나옴)
- 탈출 진행도가 오를수록 점점 빨라짐
- 오두막 문 앞에서는 **몸을 납작 숙이고 기어 들어옴** (집 안도 안전하지 않음)
- 쓰러뜨려도 40초 뒤 다시 일어남
- 멀리서 발견하면 바로 오지 않고 **가만히 서서 지켜보다가** 갑자기 돌진하거나, 연기처럼 사라져서 **등 뒤 어딘가에 다시 나타남**
- 오래 아무도 못 찾으면 플레이어 뒤쪽 시야 밖으로 순간이동해서 다가옴
- 쫓기다 옷장/차 밑에 숨는 걸 보면 와서 킁킁거리다 **문을 뜯어내거나 끌어낼 수도 있음**
- 근처의 불빛과 손전등이 깜빡이거나 꺼짐 = 괴물이 가까이 있다는 신호
- 고개가 항상 **나를** 쳐다봄

### 쓰러짐과 동료 살리기
괴물에게 치명상을 입으면 바로 죽지 않고 **쓰러져서 기어다녀요.** 35초 안에 동료가 와서 E를 4초 누르면 일어납니다.
죽거나 먼저 탈출하면 **살아있는 동료를 관전**해요 (Q/E로 바꾸기). 라운드는 모두 죽거나 탈출해야 끝나요.

### 수집품: 실종자 인식표
숲 곳곳의 벌목꾼 시신 옆에 인식표가 있어요. 주우면 그 사람의 마지막 기록이 나오고, 순위표의 "인식표" 기록이 쌓여요. (7개)

### 랜덤 공포 이벤트
환청, 멀리 서 있는 창백한 유령, 정전, 등 뒤 나뭇가지 소리가 무작위로 일어나요.

## 6. 숫자 조절하기

`src/shared/Config.luau` 파일 하나만 고치면 됩니다.
괴물 속도(`ChaseSpeed`), 재료 개수(`Count`), 라운드 시간(`RoundTime`) 등이 한글 설명과 함께 있어요.

## 7. 수익화 (로벅스) 설정

코드에는 이미 연결부가 있고, ID만 넣으면 켜집니다.

1. 먼저 Studio에서 `File` → `Publish to Roblox` 로 게임을 올립니다.
2. https://create.roblox.com → **Creations** → 내 게임 → **Monetization**
   - **Passes** 에서 게임패스 만들기 → "스타터 키트" (라운드 시작 시 조명탄 총 + 손도끼 + 조명탄 6발)
   - **Developer Products** 에서 상품 2개 만들기 → "부활", "섬광탄 3개"
3. 각각의 **ID 숫자**를 복사해서 `src/shared/Config.luau` 의 `Config.Monetization` 에 넣습니다.
   ```lua
   StarterKitPassId = 123456789,
   ReviveProductId = 987654321,
   FlashbangPackProductId = 555555555,
   ```
4. ID를 넣으면 제작 창에 "섬광탄 구매" 버튼, 죽었을 때 "지금 부활하기" 버튼이 나타납니다.

> 실제 판매는 게임이 공개(Public)된 상태여야 하고, Studio 테스트 중 구매는 로벅스가 빠지지 않는 테스트 구매예요.

## 8. 문제가 생기면

- **Connect가 안 돼요** → VS Code에서 Rojo Start를 먼저 눌렀는지 확인. 포트 번호(34872)가 Studio 플러그인 창과 같은지 확인.
- **스크립트가 안 생겨요** → Studio를 껐다 켜고 다시 Connect.
- **오류 확인** → Studio `View` → **Output** 창을 열면 빨간 글씨로 오류가 보입니다. 그 내용을 복사해서 알려주세요.
