# 3D 에셋 요청서

지금 게임의 괴물, 아이템, 도구는 전부 Roblox 기본 파트(네모, 원기둥, 공)를 조합해서 만든 것이에요.
게임은 이대로도 돌아가지만, 아래 모델을 만들어 주시면 **코드 수정 없이** 자동으로 교체됩니다.

## 0. 꼭 직접 만들어야 하나요?

| 구분 | 직접 제작 추천 | 대안 |
|---|---|---|
| 괴물 (숲지기) | ✅ 가장 효과가 큼. 게임의 얼굴 | Creator Store에도 괴물은 있지만 우리 스토리(사슴 두개골 + 뿔)에 맞는 건 드묾 |
| 탈출 부품 6종 | ✅ 플레이어가 계속 찾아다니는 물건이라 눈에 잘 띄어야 함 | 지금 파트 조합 모양도 나쁘진 않음 |
| 도구 6종 | ✅ 1인칭이라 화면에 항상 보임 | Creator Store "flare gun", "hatchet" 등 |
| 재료 5종 | 선택 | 지금 파트 조합으로 충분 |
| 나무, 바위, 오두막, 트럭 | ❌ 직접 만들 필요 없음 | Creator Store 무료 모델 (아래 7번) |

**추천 순서:** 괴물 → 탈출 부품 → 도구 → 나머지

## 1. 공통 사양 (모든 모델)

| 항목 | 값 |
|---|---|
| 파일 형식 | **FBX** 또는 **GLB** (OBJ도 가능하지만 텍스처가 잘 안 붙음) |
| 폴리곤 수 | 아이템 3,000개 이하 / 도구 5,000개 이하 / 괴물 20,000개 이하 (삼각형 기준) |
| 텍스처 | PNG, 1024×1024 이하. 색(Base Color) 필수, 노멀/러프니스는 있으면 좋음 |
| 방향 | 앞쪽 = -Z (Roblox 기준). 모르면 그냥 만들어 주세요, Studio에서 돌리면 됨 |
| 기준점 | 바닥 가운데 |
| 크기 | 상관없음 (코드가 자동으로 맞춤) |
| 스타일 | 약간 낡고 더러운 사실풍 / 저폴리곤도 OK. 1990년대 한국 산골 벌목장 느낌 |

> Roblox는 메쉬 하나당 삼각형 2만 개, 텍스처 1024px 제한이 있어요. 넘으면 업로드가 안 되거나 자동으로 줄어들어요.

## 2. 괴물 "숲지기" (가장 중요)

### 생김새
- 키 약 4~5m, 비쩍 마른 사람 형태. 팔이 무릎 아래까지 내려올 만큼 길다
- 머리: **하얀 사슴 두개골** (눈구멍은 텅 비어 있고 안쪽에 붉은 빛), 커다란 **사슴뿔**
- 몸: 검은 나무껍질 같은 피부, 갈비뼈와 등뼈가 드러남
- 손: 나뭇가지 같은 길고 뾰족한 손가락 3개
- 다리: 사슴처럼 역관절이면 더 무서움 (선택)
- 몸 곳곳에 이끼, 찢어진 천 조각

### AI 이미지/3D 생성용 프롬프트 (그대로 복사해서 쓰세요)
```
A tall, emaciated forest creature, 4 meters tall, humanoid body with extremely long thin arms
reaching below the knees, white deer skull for a head with large branching antlers, empty eye
sockets with faint red glow, dark bark-like skin with exposed ribs and spine, three long
twig-like clawed fingers, digitigrade deer legs, moss and torn cloth hanging from the body,
horror game character, T-pose, full body, front view, neutral lighting, game-ready low poly
```

### 리깅 (뼈대) — 움직이게 하려면 필요
- Meshy, Tripo 같은 3D 생성 사이트에는 **"Auto Rig (Humanoid)"** 기능이 있어요. 그걸 켜고 FBX로 받으세요.
- 애니메이션도 같이 받을 수 있으면 아래 이름으로 받아 주세요:

| 이름 | 동작 |
|---|---|
| Idle | 가만히 서서 어깨를 들썩임 |
| Walk | 느리게 휘청거리며 걷기 |
| Run | 앞으로 숙이고 팔을 뻗은 채 달리기 |
| Attack | 긴 팔로 할퀴기 |
| Stunned | 두 팔로 얼굴(두개골)을 가리고 움츠림 |
| Scream | 고개를 젖히고 포효 (선택) |

- 리깅이 어려우면 **뼈대 없이 모델만** 주셔도 돼요. 그러면 지금처럼 코드로 움직이게 하려고 **머리 / 몸통 / 왼팔 / 오른팔 / 왼다리 / 오른다리를 따로 나눈 파일**로 주시면 가장 좋아요.

## 6. 만든 모델을 게임에 넣는 법

1. Roblox Studio → 위쪽 **Home** 탭 → **Import 3D** → FBX/GLB 파일 선택 → Import
   - 괴물처럼 뼈대가 있는 모델은 Rig Type이 자동으로 잡혀요. 그대로 Import.
2. Explorer에서 **ReplicatedStorage** 안에 폴더를 만들어요 (오른쪽 클릭 → Insert Object → Folder):
   ```
   ReplicatedStorage
   └ Assets            ← 폴더 이름 정확히
     ├ Items           ← Fuse, Battery, FuelCan, CarKey, Antenna, Rune, DogTag, Scrap, Wood, Herb, Gunpowder, Cloth
     ├ Tools           ← FlareGun, Axe, Flashbang, Trap, Medkit, SealStake
     └ Monster         ← 괴물 모델 (이름을 Monster로)
   ```
3. Import된 모델을 해당 폴더로 끌어다 놓고 **이름을 표의 영어 이름 그대로** 바꿔요.
4. 괴물만 추가 조건:
   - 모델 안에 `HumanoidRootPart`(파트)와 `Humanoid`가 있어야 해요. 리깅된 FBX를 Import하면 보통 자동으로 생겨요.
   - 애니메이션이 있다면: 애니메이션을 Roblox에 올려서(Animation Editor → Import → Publish) 받은 ID로
     `Animation` 오브젝트를 만들고, 괴물 모델 안 `Animations` 폴더에 `Idle`, `Walk`, `Run`, `Attack`, `Stunned` 이름으로 넣어요.
   - 눈 부분 파트 이름에 `Eye`가 들어가면 기절할 때 눈 색이 바뀌어요.
5. **File → Save to Roblox** 로 장소를 저장하세요. (Assets 폴더는 Rojo가 아니라 Studio 장소 파일에 저장돼요)
6. Play → 바뀐 모델이 나오면 성공!

> 모델이 이상한 방향을 보고 있으면 Studio에서 모델을 선택하고 Rotate 툴로 돌린 뒤 저장하면 돼요.

## 7. 직접 안 만들어도 되는 것 — Creator Store 무료 모델

Studio **Toolbox(도구 상자)** → Marketplace 검색:

| 용도 | 검색어 |
|---|---|
| 소나무 | `low poly pine tree`, `realistic pine tree` |
| 오두막 | `abandoned cabin`, `wooden shack` |
| 트럭 | `logging truck`, `old pickup truck` |
| 바위 / 고목 | `rock pack`, `dead tree` |
| 소리 | Toolbox → Audio 탭: `forest ambience night`, `monster scream`, `heartbeat`, `footstep heavy`, `whisper` |

⚠️ **무료 모델 주의:** 무료 모델 안에 `Script`가 들어 있으면 해킹 스크립트일 수 있어요. 넣은 뒤 Explorer에서 모델을 펼쳐서 Script가 있으면 지워 주세요. (Assets 폴더에 넣은 모델은 코드가 자동으로 스크립트를 지워요.)

소리 ID는 `src/shared/SoundList.luau` 에 숫자로 넣으면 바로 켜져요.
어떤 소리가 필요한지, 검색어는 뭔지 전부 [소리_넣기.md](소리_넣기.md) 에 정리돼 있어요.
