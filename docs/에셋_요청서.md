# 3D 에셋 요청서

지금 게임의 괴물, 나무, 아이템, 도구는 전부 Roblox 기본 파트(네모, 원기둥, 공)를 조합해서 만든 것이에요.
땅·바위·절벽은 진짜 지형(Terrain)이고, 조명·안개·비는 실사풍으로 맞춰 놨어요.
게임은 이대로도 돌아가지만, **"실사 같은" 느낌의 마지막 한 걸음은 모델(메시)** 입니다.
아래 모델을 만들거나 구해서 넣어 주시면 **코드 수정 없이** 자동으로 교체됩니다.

**효과가 큰 순서: ① 나무(소나무) → ② 괴물 → ③ 도구 → ④ 나머지**
(나무는 화면의 대부분을 차지하고, Creator Store에서 무료로 5분이면 구할 수 있어서 가장 가성비가 좋아요. 아래 7번)

## 0. 꼭 직접 만들어야 하나요?

| 구분 | 직접 제작 추천 | 대안 |
|---|---|---|
| 괴물 (숲지기) | ✅ 가장 효과가 큼. 게임의 얼굴 | Creator Store에도 괴물은 있지만 우리 스토리(사슴 두개골 + 뿔)에 맞는 건 드묾 |
| 탈출 부품 6종 | ✅ 플레이어가 계속 찾아다니는 물건이라 눈에 잘 띄어야 함 | 지금 파트 조합 모양도 나쁘진 않음 |
| 도구 6종 | ✅ 1인칭이라 화면에 항상 보임 | Creator Store "flare gun", "hatchet" 등 |
| 재료 5종 | 선택 | 지금 파트 조합으로 충분 |
| 나무, 고목, 그루터기, 덤불 | ❌ 직접 만들 필요 없음 | **Creator Store 무료 모델을 넣으면 숲 전체가 자동으로 바뀜** (아래 7번) |
| 오두막, 트럭 | ❌ | 코드로 만든 것을 그대로 쓰는 걸 추천 (문 크기, 숨는 자리 등이 맞춰져 있어요) |

## 1. 공통 사양 (모든 모델)

| 항목 | 값 |
|---|---|
| 파일 형식 | **FBX** 또는 **GLB** (OBJ도 가능하지만 텍스처가 잘 안 붙음) |
| 폴리곤 수 | 아이템 3,000개 이하 / 도구 5,000개 이하 / 괴물 20,000개 이하 (삼각형 기준) |
| 텍스처 | PNG, 1024×1024 이하. 색(Base Color) 필수, 노멀/러프니스는 있으면 좋음 |
| 방향 | 앞쪽 = -Z (Roblox 기준). 모르면 그냥 만들어 주세요, Studio에서 돌리면 됨 |
| 기준점 | 바닥 가운데 |
| 크기 | 상관없음 (코드가 자동으로 맞춤) |
| 스타일 | 약간 낡고 더러운 사실풍 / 저폴리곤도 OK. 1990년대 한국 산골 벌목장 느낌 |

> Roblox는 메쉬 하나당 삼각형 2만 개, 텍스처 1024px 제한이 있어요. 넘으면 업로드가 안 되거나 자동으로 줄어들어요.

## 2. 괴물 "숲지기" (가장 중요)

### 생김새
- 키 약 4~5m, 비쩍 말라붙은 사람 형태. 등이 굽었고, 팔이 땅에 닿을 듯 길다
- 머리: **누렇게 바랜 사슴 두개골**. 주둥이가 길고 **아래턱이 벌어진다**. 뿔은 **왼쪽만 온전하고 오른쪽은 부러져 있다**
- 눈: 눈구멍은 텅 비어 캄캄하다. (빛을 받으면 번쩍이는 건 코드가 처리 → 눈알 파트 이름을 `Eye` 로)
- 몸: 검게 말라붙은 가죽, 갈비뼈와 등뼈 돌기가 드러남. 등에 이끼가 늘어져 있다
- 손: 길고 뾰족한 갈고리 손톱 4개
- 다리: 사슴처럼 무릎이 꺾여 있고 발굽이 있다
- 허리에 **낡은 노란 안전모 3개**가 끈으로 매달려 있다 (사라진 벌목꾼들의 것), 뿔에는 금줄(새끼줄) 조각

### AI 이미지/3D 생성용 프롬프트 (그대로 복사해서 쓰세요)
```
A tall emaciated forest spirit creature, 4.5 meters tall, hunched humanoid body with extremely
long thin arms almost touching the ground, weathered yellowed deer skull head with long snout
and open lower jaw, one full branching antler and one broken antler, empty black eye sockets,
dried black leathery skin with exposed ribs and spine ridges, four long hooked claws on each
hand, digitigrade deer legs with hooves, three old yellow construction hard hats hanging from
its waist on ropes, moss and frayed straw rope hanging from body and antler, Korean folk horror,
photorealistic, muted dark colors, horror game character, T-pose, full body, front view,
neutral lighting, game-ready
```

### 리깅 (뼈대) — 움직이게 하려면 필요
- Meshy, Tripo 같은 3D 생성 사이트에는 **"Auto Rig (Humanoid)"** 기능이 있어요. 그걸 켜고 FBX로 받으세요.
- 애니메이션도 같이 받을 수 있으면 아래 이름으로 받아 주세요:

| 이름 | 동작 |
|---|---|
| Idle | 가만히 서서 어깨를 들썩임 |
| Walk | 느리게 휘청거리며 걷기 |
| Run | 앞으로 숙이고 팔을 뻗은 채 달리기 |
| Attack | 긴 팔로 할퀴기 |
| Stunned | 두 팔로 얼굴(두개골)을 가리고 움츠림 |
| Scream | 고개를 젖히고 포효 (선택) |

- 리깅이 어려우면 **뼈대 없이 모델만** 주셔도 돼요. 그러면 지금처럼 코드로 움직이게 하려고 **머리 / 몸통 / 왼팔 / 오른팔 / 왼다리 / 오른다리를 따로 나눈 파일**로 주시면 가장 좋아요.

## 6. 만든 모델을 게임에 넣는 법

1. Roblox Studio → 위쪽 **Home** 탭 → **Import 3D** → FBX/GLB 파일 선택 → Import
   - 괴물처럼 뼈대가 있는 모델은 Rig Type이 자동으로 잡혀요. 그대로 Import.
2. Explorer에서 **ReplicatedStorage** 안에 폴더를 만들어요 (오른쪽 클릭 → Insert Object → Folder):
   ```
   ReplicatedStorage
   └ Assets            ← 폴더 이름 정확히
     ├ Items           ← Fuse, Battery, FuelCan, CarKey, Antenna, Rune, DogTag, Scrap, Wood, Herb, Gunpowder, Cloth
     ├ Tools           ← FlareGun, Axe, Flashbang, Trap, Medkit, SealStake
     ├ Monster         ← 괴물 모델 (이름을 Monster로)
     └ Props           ← Pine(소나무), DeadTree(고목), Stump(그루터기), Bush(덤불)
   ```
3. Import된 모델을 해당 폴더로 끌어다 놓고 **이름을 표의 영어 이름 그대로** 바꿔요.
4. 괴물은 **가져온 그대로** `Assets` 폴더에 넣고 이름만 `Monster` 로 바꾸면 돼요.
   - `HumanoidRootPart` 나 `Humanoid` 가 없어도 코드가 알아서 만들어 붙이고, 키도 자동으로 맞춰요 (`Config.MonsterModel.Height`).
   - **애니메이션**: 괴물 모델이 Workspace에 있을 때 애니메이션 편집기로 동작 FBX를 하나씩 가져와서(⋯ → 가져오기 → 파일에서 가져오기)
     **Roblox에 게시** 하고, 받은 번호를 `src/shared/Config.luau` 의 `Config.MonsterModel.Animations` 에 넣어요.
     - 가져오기 설정에서 **휴식 포즈 소스는 `가져온 리그`**, **배율 조정 값은 모델을 가져올 때 쓴 값과 같게**(숲지기는 `0.0356`) 맞추세요.
       기본값(`가져온 리그(0으로 설정된 회전)`)으로 가져오면 몸이 눕고, `애니메이션 편집기 리그`로 가져오면 몸이 두 배로 늘어나요.
     - 숲지기 동작 4개는 2026-11-17에 이미 게시해서 번호가 들어가 있어요. 동작 파일을 바꿨을 때만 다시 하면 돼요.
     | 이름 | 동작 | 숲지기 패키지의 파일 |
     |---|---|---|
     | `Idle` | 가만히 서 있기 | `supjigi-still.fbx` |
     | `Walk` | 걷기 | `supjigi-walking.fbx` |
     | `Run` | 달리기 | `supjigi-running.fbx` |
     | `Charge` | 쫓아올 때 팔을 뻗고 달리기 (없으면 Run) | `supjigi-charge-prototype.fbx` |
     | `Attack` / `Stunned` / `Scream` | 할퀴기 / 움츠림 / 울부짖기 (없어도 됨) | 없음 |
   - 번호가 `0` 인 동작은 재생되지 않아요. 전부 `0` 이면 괴물이 T자 자세로 미끄러지듯 움직여요.
   - 지켜보기 중 플레이어가 쳐다보면 **걷던 동작 그대로 그 자리에서 굳어요.**
   - 괴물이 뒷걸음질로 다니면 `Config.MonsterModel.FaceYaw` 를 `180` 으로 바꾸세요.
   - 눈 부분 파트 이름에 `Eye`가 들어가면 손전등 빛을 받을 때 짐승 눈처럼 번쩍여요 (통짜 메시에는 해당 없음).
5. **File → Save to Roblox** 로 장소를 저장하세요. (Assets 폴더는 Rojo가 아니라 Studio 장소 파일에 저장돼요)
6. Play → 바뀐 모델이 나오면 성공!

> 모델이 이상한 방향을 보고 있으면 Studio에서 모델을 선택하고 Rotate 툴로 돌린 뒤 저장하면 돼요.

## 7. 직접 안 만들어도 되는 것 — Creator Store 무료 모델

### ⭐ 나무 바꾸기 (5분, 효과 최고)
숲의 나무 약 500그루는 `Assets/Props` 폴더에 모델이 있으면 **전부 그 모델로 자동 교체**됩니다. 높이는 코드가 맞춰요.

1. Studio **Toolbox(도구 상자)** → Marketplace → 모델에서 아래 검색어로 찾기
2. 마음에 드는 걸 클릭해서 맵에 꺼낸 뒤, Explorer에서 `ReplicatedStorage > Assets > Props` 폴더로 끌어다 놓기
3. 이름을 아래 표의 **영어 이름**으로 바꾸기 → File → Save to Roblox → Play

| 이름 | 무엇 | 검색어 | 고르는 요령 |
|---|---|---|---|
| `Pine` | 소나무 (숲의 대부분) | `realistic pine tree`, `spruce tree`, `conifer` | 키 크고 어두운 색. **메시(MeshPart) 1~3개짜리 가벼운 것** (500그루가 복사되니 무거우면 느려져요) |
| `DeadTree` | 잎 없는 고목 | `dead tree`, `bare tree` | 가지가 앙상한 것 |
| `Stump` | 그루터기 | `tree stump` | |
| `Bush` | 덤불 (숨는 곳) | `bush`, `fern`, `shrub` | 사람 키 정도 |

넣지 않은 종류는 지금처럼 파트로 만든 나무가 나옵니다.

### 그 밖에

Studio **Toolbox(도구 상자)** → Marketplace 검색:

| 용도 | 검색어 |
|---|---|
| 소리 | Toolbox → Audio 탭: `rain loop`, `thunder`, `forest ambience night`, `monster scream`, `heartbeat`, `whisper` |

⚠️ **무료 모델 주의:** 무료 모델 안에 `Script`가 들어 있으면 해킹 스크립트일 수 있어요. 넣은 뒤 Explorer에서 모델을 펼쳐서 Script가 있으면 지워 주세요. (Assets 폴더에 넣은 모델은 코드가 자동으로 스크립트를 지워요.)

소리 ID는 `src/shared/SoundList.luau` 에 숫자로 넣으면 바로 켜져요.
어떤 소리가 필요한지, 검색어는 뭔지 전부 [소리_넣기.md](소리_넣기.md) 에 정리돼 있어요.

## 8. 외부 도구가 필요할 때 (전부 선택 사항)

| 하고 싶은 것 | 도구 | 왜 |
|---|---|---|
| 괴물을 진짜 3D 모델로 | **Meshy** 또는 **Tripo** (AI 3D 생성 웹앱, 무료 체험 있음) | 위 2번 프롬프트를 넣으면 모델 + 자동 리깅 + 걷기/달리기 애니메이션까지 FBX로 받을 수 있어요 |
| 받은 모델 다듬기 | **Blender** (무료) | 폴리곤 줄이기(Decimate), 방향/크기 맞추기, 머리·팔·다리 나누기 |
| 죽은 사람 목소리 (Mimic) | **ElevenLabs** 같은 AI 음성, 또는 직접 녹음 | "도와주세요… 여기예요…" 를 속삭이는 한국어 음성이 있으면 목소리 흉내 연출이 훨씬 무서워져요. 6초 이하로 잘라서 Studio에 오디오로 올리면 됩니다 |
| 게임 아이콘/썸네일 | 이미지 생성 AI | 게임 페이지에 쓸 그림 |
